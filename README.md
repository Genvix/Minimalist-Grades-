# Minimalist Grades
A minimalist, customizable grade tracker for students.

# About

Minimalist Grades is an open-source app designed to make it simple to record school grades, organize them by subject and trimester, and automatically calculate averages.

The default grading system is based on the Panamanian school grading system, while the calculation system is designed to be customizable.

# Planned Features

## Grade Management

- Grade tracking by subject
- Daily grades and appreciation grades
- Trimester exams
- Automatic category averages
- Trimester averages
- Cumulative averages

## Customization

- Customizable grading systems
- Custom grading scales
- Custom decimal handling

## Goals

- Target average for each subject
- Calculation of grades needed to reach a target

## School Organization

- Multiple trimesters
- School timetable
- Option to keep subjects and timetable when creating a new trimester

## Storage

- Local data storage
- Offline functionality

## Status

Early Development

The application is currently being designed. Development has not started yet.
